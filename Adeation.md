# Adeation

## Project concept
Personal Productivity Agent is a web-based productivity assistant that helps users plan their day, prioritize work, and maintain focus by turning vague tasks into a clear action plan.

## Problem
People often struggle with:
- too many tasks and no clear priority
- unclear next actions for the day
- context switching and lost focus
- difficulty turning goals into actionable steps

## Goal
Create a one-day hackathon MVP that demonstrates an AI-powered productivity agent that helps users:
- convert goals into daily tasks
- rank work by urgency and impact
- suggest focus blocks and next actions
- summarize progress and recommend the next step

## User value
- save time deciding what to do first
- reduce overwhelm and decision fatigue
- create clearer daily execution plans
- maintain momentum through AI-guided next steps

## Hackathon constraints
- Must be a web app
- Must use Microsoft Agent Framework
- Must use Copilot SDK
- Must be deployable to Azure
- Should be simple enough to deliver as an MVP within one day

## MVP idea
A single-page web app where a user enters a list of tasks or goals. The agent analyzes them, sorts them by importance, suggests a top-three priority queue, and proposes a focused work plan for the day.

## Proposed user flow
1. User enters goals or tasks.
2. Agent analyzes scope, urgency, and effort.
3. Agent ranks tasks by priority.
4. Agent proposes a daily schedule with work blocks.
5. User reviews results and continues with next actions.
6. Agent can summarize the day or suggest next steps.

## Core features
- Task input form
- AI-based priority recommendation
- Daily focus plan
- Next action suggestions
- Short summary output

## Non-goals for MVP
- multi-user collaboration
- deep calendar integrations
- advanced analytics dashboards
- enterprise authentication
- complicated workflow orchestration beyond demo needs

## Success metric for the hackathon
The app should successfully run as a web app, the agent should provide meaningful recommendations, and the app should be deployed to Azure with a working demo URL.
